# 小小世界 · Demo Prototype

三个可直接打开的页面：

- `index.html`：产品理念与产品介绍网站
- `prototype.html`：手表端 + 家长手机端可交互原型
- `deck.html`：滚动式产品 Pre，支持方向键翻页

## 交互范围

### 原型核心闭环（prototype.html）

- 手表端 / 家长端切换
- 手表端「自由探索 / 今日任务」切换
- 自由探索：拍照 → 对象选择 → 对象对话 → 继续语音
- 语音承接：说一说 → 我在听 → 结束回到探索
- 今日任务：查看进度 → 完成任务
- 家长端：查看今日探索、情绪线索和世界档案入口

### Pre 展示案例（非手表核心流程）

- Community 的「基地二号」：用于说明共同发现与邀请朋友的产品案例
- Collection：用于说明对象档案与关系故事的产品案例
- 情绪卡：用于说明“孩子表达 → 家长看见”的转交机制

以上三部分服务于产品叙事展示，不代表手表端必须经过的连续交互步骤。

页面使用纯 HTML / CSS / JS，无需安装依赖；适合直接放入静态托管或 GitHub Pages。
